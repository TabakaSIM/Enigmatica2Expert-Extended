---
name: issue-report
description: Write and file a bug report to a mod author's repo. Load when reporting a log error/crash upstream via `gh issue create`.
---

Before writing: get the mod's source (`pnpm mod-source <modid>`), confirm the cause in code, and check for an existing issue (`gh issue list --repo <owner>/<repo> --search ...`).

## Body

1. First line, gray disclaimer: `> <sub>🤖 This report was generated by AI</sub>`
2. One or two sentences on what is wrong. No preamble, no "Steps to reproduce" unless non-obvious.
3. The verbatim log/stacktrace in a fenced block (trim to the relevant frames).
4. GitHub permalink to the offending lines: `https://github.com/<owner>/<repo>/blob/<full-sha>/<path>#L1-L5` — always a full commit sha, never a branch.
5. Say plainly if it is harmless/cosmetic.
6. Last line: meta info — ```<Mod> `<ver>`, Cleanroom `<ver>`, Modpack `<modpack-name>`.```

Do not suggest fixes or patches unless asked. Title: short, with the identifier in backticks.
